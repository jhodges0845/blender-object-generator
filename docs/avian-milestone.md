# Avian provider milestone

Avian is the next provider milestone after Human and Quadruped.

The implementation should begin directly with canonical Avian identity: provider key `avian`, `AvianProvider`, and Avian-named geometry, rigging, animation, tests, generated metadata, and documentation. No alternate provider name is needed.

Initial work should prove a small host-independent Avian parameter/mesh contract through the existing generic Blender Generator path before adding avian-specific rigging, wing/tail deformation, surfacing, and flight/locomotion behavior.
