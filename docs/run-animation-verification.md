# Run verification

After installing this branch in Blender:

1. Generate and rig Human 1.0.
2. In Animations, generate Idle, Walk, and Run.
3. Preview Run and confirm a visibly faster, stronger cycle than Walk.
4. Export to Godot and confirm the clip list includes `Idle`, `Walk`, and `Run`.
5. Repeat with Dog and confirm its Run is distinct from Walk.
6. Optionally rename the Run export name and confirm the engine receives the renamed clip.
