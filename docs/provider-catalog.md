# Provider catalog

Current canonical provider identities:

- **Human** — connected deforming biped foundation with Idle, Walk, and Run.
- **Quadruped** — connected deforming four-legged foundation with Idle, Walk, and Run.
- **Box** — static prop foundation.
- **Avian** — next active provider milestone.

New provider code, generated metadata, tests, and documentation should use the canonical identity directly. Historical persisted identifiers are compatibility inputs only and should not reappear as active provider concepts.
